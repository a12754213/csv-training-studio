# AI Agent Hub v3.2：使用與補充設定

## 先試，不需要填 API Key

1. 開啟網站「AI 任務」。點「分析台積電股價未來趨勢」，再按「開始分析」。
2. 系統讀取最近六個月份的證交所上市股票日成交資料，顯示資料日期、均線、價格變動及最大回撤。
3. 點「訓練並回測股價模型」比較 Ridge、Random Forest 和 Naive；模型以訓練期間內的驗證集選擇，最後才評估保留測試資料。
4. 查看「資料與圖表」下載原始 CSV，或按「用這份資料接續 CSV 訓練」。不用重新上傳。
5. 公開網址可直接貼入任務欄；上傳 CSV、文字 PDF、SRT/VTT 也不需要 API Key。

六個月份包括當月，當月可能不完整；不足 100 筆不能回測。若跨度 20 筆導致可用訓練樣本太少，增加為 9 或 12 個月份。股價工具目前支援證交所上市代碼（例如 2330、0050），不含上櫃、美股 ADR。無法唯一辨識的公司／市場會走一般搜尋，不會亂選股票。

## 啟用「自動找資料 → 閱讀來源 → AI 報告」

在首頁左側「連線設定」輸入你自己的金鑰，並在「分析選項」開啟 AI 報告。

| 設定 | 用途 | 未設定時 |
| --- | --- | --- |
| Brave Search API Key | 自動搜尋公開網路索引 | 可讀指定網址、分析台股及檔案；不能全網找新聞 |
| OpenAI API Key | 用最多三個來源片段生成有編號的研究報告；選用圖片理解／音訊轉錄 | 保留實際來源摘錄、表格統計、股價統計；沒有 LLM 綜合解讀 |
| 圖片／音訊傳送選項 | 允許該次上傳傳給 OpenAI | 不會將檔案送往外部模型 |

申請入口：
- Brave：[Search API](https://brave.com/search/api/)
- OpenAI：[API Keys](https://platform.openai.com/api-keys)

不要將金鑰貼給聊天助理、寫入 GitHub 或放在報告。公開網站預設使用每個訪客自己的工作階段金鑰；不從伺服器自動借用管理員金鑰。工作階段結束不保證保留輸入。

若你在**已有登入驗證的私有部署**中想使用伺服器金鑰，可在環境變數設定 `AI_AGENT_PRIVATE_DEPLOYMENT=1`，並以環境變數或 Streamlit Secrets 提供 `BRAVE_SEARCH_API_KEY`、`OPENAI_API_KEY`。這個開關**不提供登入功能**，不能在無登入的公開網站直接開啟。私有模式也不會把伺服器 Key 回填到網頁欄位。

金鑰顯示「已提供」只代表有輸入，實際授權與額度要在執行時驗證。此程式不會代替你註冊服務、開啟計費或同意第三方條款。

## 結果怎麼看

- **分析結論**：股價統計、模型回測或 AI 來源研究。未開啟 AI 時顯示實際摘錄，清楚區分分析深度。
- **資料與圖表**：均線、原始價格、網頁表格、CSV 欄位品質；可下載或轉交 CSV 訓練。
- **來源與缺口**：實際取得的網址、搜尋索引、無法讀取的來源、未取得月份。
- **執行紀錄**：工具順序、時間、完成／部分完成／無可用來源，下載 JSON。金鑰不在其中。

修改指令、上傳檔案或分析選項會清除舊分析；修改預測跨度會清除舊回測。重新執行不會把之前的結果冒充成最新結果。單篇網站失敗不會丟棄其餘來源；AI 摘要服務失敗仍保留已擷取內容。

## 股價分析界線

來源：[證交所個股日成交資訊](https://www.twse.com.tw/zh/trading/historical/stock-day.html)。使用官網按月 JSON，固定 HTTPS 目的地，限制最多 12 次月份查詢並間隔請求；格式改變、服務限流或不可用會明確失敗。

- 收盤價是**未還原日成交價**，不是即時價格，也不是含息報酬。除權息／分割可能造成模型與指標失真。
- 缺月份或無效價格資料時，保留可取得統計但不執行模型回測。無法辨識所有停牌或漏掉的交易日，仍須檢查來源。
- 模型預測的是未來第 1／5／20 筆觀測值，不猜休市日，不生成未來每天的價格路徑。
- 採固定模型、滾動起點測試；只用當時已觀測資料。MAE、RMSE 和 Naive 對照一起呈現。
- 若模型沒有勝過 Naive，畫面會直接提醒。即使勝過一次，也不能推論可獲利。
- 尚未建置還原價、完整財報估值、交易成本回測、機率區間校準、多市場行情或自動交易。新聞摘要與股價模型分開顯示，新聞沒有偷偷加入歷史訓練造成時間洩漏。

## 需要你補充、無法只靠程式碼完成的部分

| 功能 | 你需要做的事 | 目前已準備 |
| --- | --- | --- |
| 自動搜尋／AI 彙整 | 申請各自 API Key，啟用帳戶額度，填入左側設定 | 搜尋、讀取來源、報告和失敗處理已串好；未用你的金鑰驗收 |
| ChatGPT 直接呼叫 | 選擇本機 MCP 或有 HTTPS／驗證的遠端主機，於支援的客戶端完成連線 | STDIO 與 HTTP MCP 提供 `research_public_topic`、`analyze_twse_stock`；尚未替你的帳號連線 |
| 動態網頁 | 準備限制網路出口的隔離容器／VM，安裝 Chromium | 沿用 `web.render`；普通公開 Streamlit 部署不自動啟用 |
| YouTube 字幕／資訊 | 本機安裝 `requirements-agent-extras.txt`，設定 `AI_AGENT_YOUTUBE_ENABLED=1` | 已有字幕／資訊工具；不保證平台允許擷取，不含完整影片畫面理解 |
| 長期記憶／排程 | 指定私有持久磁碟與常駐 Worker；需要通知時再選通知管道 | 已有本機 SQLite／Worker；首頁紀錄只是本次工作階段摘要 |
| 任意網站登入／驗證碼 | 由你登入並取得網站允許的存取方式 | 不繞過登入、付費牆或防機器人限制 |

本機設定詳見 [CHATGPT_LOCAL.md](CHATGPT_LOCAL.md)；遠端現況見 [AGENT_CORE_3.md](AGENT_CORE_3.md)；多媒體／排程見 [AGENT_CAPABILITIES.md](AGENT_CAPABILITIES.md)。


測試替身驗證搜尋與 AI 整合的控制流程，不等於真實金鑰授權成功。股價的實際連線驗收與測試結果記錄於 `VALIDATION.md`。任務分派仍是可解釋的有限規則，不是可自由執行任意程式的萬能 Agent。
