# v3.3：自主規劃、接續對話與多來源整合

## 怎麼使用

1. 首頁「工作方式」選 **對話與多來源 Agent**。
2. 輸入這次目標，可一次加入最多六份檔案、合計 30 MB；網址可直接寫在指令中，每輪最多三個明確網址。
3. 沒有模型金鑰時可先使用「整理來源」：讀取檔案、指定公開網址，或取得台股日成交資料；這個模式沒有模型生成的跨來源解讀。
4. 在左側填入自己的 OpenAI Key，勾選 **使用 AI 自主規劃與整合**。需要全網搜尋時另填 Brave Key。
5. 如果要模型閱讀附檔內文，勾選 **允許 AI 讀取附檔文字摘錄、表格前五列**。不勾選時，模型只能取得檔名、欄位與檔案概況；PDF／字幕原文仍可在本地來源頁查看。
6. 開始後，Agent 會先規劃，再依實際工具回傳選下一步。結果在「對話與報告」，下方對話框可繼續提出要求。

例如：

> 比較這兩份 CSV 的概況，再讀取我提供的公開報告，指出來源一致或矛盾的地方。

接著可以說：

> 再加入這份 PDF 比較。

> 改成聯發科的股價趨勢，並保留同樣的分析目的。

> 針對這份表格，建議如何預測是否流失。

模型可提出 CSV 訓練建議；到「資料與訓練」選擇資料、按「接續 CSV 訓練」，再確認目標及設定才會真的訓練。若有合法建議，會預選目標欄位與分類／回歸／時間序列模式；時間序列也帶入日期欄、視窗及跨度，仍需確認後執行。

## 目前流程

模型透過 OpenAI Responses API 的 function calling 選擇固定工具：

| 工具 | 作用 |
| --- | --- |
| `outline_task` | 提出／調整最多六步工作計畫 |
| `search_web` | Brave 公開索引搜尋；每輪最多三次 |
| `read_web` | 讀取已提供或搜尋實際回傳的網址；支援靜態網頁、表格、1.5 MB 內公開 PDF、已配置環境的 YouTube 字幕 |
| `render_web` | 在已配置隔離瀏覽器的環境讀取已知網址；不自動啟用環境 |
| `inspect_file` | 選擇並讀取已上傳的 CSV、PDF、圖片、音訊或字幕 |
| `analyze_stock` | 取得 TWSE 上市股票日成交資料及統計 |
| `propose_training` | 為已取得的表格提出訓練建議，不執行訓練 |
| `ask_user` | 缺少必要資訊時提出問題，等待下一輪回答 |
| `finish_report` | 使用實際來源編號完成報告 |

每輪最多 **八個規劃模型回合**，每回合一項工具動作，包含規劃與完成報告；每份規劃模型回傳最多 1,600 輸出 token。若工具另外呼叫圖片理解或音訊轉錄 API，其用量另計。步數或資料大小達上限時保留已取得內容，讓使用者縮小問題後接續。並不是無限背景研究。

這是模型根據觀察結果逐步選工具的流程；「整理來源」則是明確的非模型流程。來源失敗後模型可換其他結果／改寫搜尋，重複的相同動作在本輪重用結果，不會無限重試。

預設模型為 `gpt-6-luna`，使用 `reasoning.effort=none` 與 `store=false`；金鑰需要該模型權限。官方規格參考：
- [OpenAI function calling](https://developers.openai.com/api/docs/guides/function-calling)
- [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)

## 資料與權限

- 「允許本輪查詢公開網站與行情」可關閉。關閉後，模型無法用搜尋、讀網頁、動態瀏覽器或行情工具；仍可使用附檔及既有來源。
- OpenAI 接收目標、必要對話、檔名、欄位與工具概況；附檔文字／前五列只有在允許讀取內容時才提供。音訊及圖片理解亦需此選項和模型金鑰。
- 取消附檔內容允許後，新的模型請求不帶之前的助手回答，避免再傳送可能引用附檔內文的舊回答；檔名與來源清單仍用於接續工作。
- 金鑰只放在受控服務請求的標頭／參數中，不是可由模型指定的工具參數，不寫進對話紀錄；常見 `sk-` 字串在匯出時會遮蔽。原始附檔留在使用者工作階段。
- 網址只能來自使用者明確提供、已讀來源或本輪搜尋結果。沿用既有 DNS／公開 IP、robots、轉址與大小限制。
- 工具清單沒有 shell、任意程式執行、登入、交易或直接訓練。網頁與文件內的指令不能增加工具權限。

## 對話保存與輸出

每項任務保留初始目標、最近十二則對話、最多六份附檔、二十四個來源及最近二十四筆資料結果。檔案可以跨輪重用，已有來源維持相同編號。這些只在本次 Streamlit 工作階段內，尚未跨裝置持久保存；另開任務清除當前資料，API 設定仍可保留。

可下載 Markdown 研究報告、JSON 任務紀錄及選定 CSV。來源頁分別標示擷取時間（台灣時間）、來源提供的發表日期（若有）與無法讀取的項目。官方網域分類、引用編號與來源數量都不等於已完成獨立事實查核。

## 驗收範圍

已使用測試模型重現：規劃 → 搜尋 → 一個來源失敗 → 改讀另一個來源 → 分析兩份 CSV → 有來源編號的報告；另驗證追問、資料傳送選項、未知網址／訓練拒絕、錯誤引用修正、步數上限及模型失敗時保留資料。

實際瀏覽器驗收使用合成資料，測試兩份 CSV 上傳、工作階段追問、來源不重複以及資料交接訓練。**尚未持有使用者的付費金鑰，所以真實帳戶的 OpenAI／Brave 授權、額度與模型表現尚未完成驗收。**

完整影片逐幀分析、OCR、跨裝置記憶、常駐背景任務與 ChatGPT 客戶端實際連接，仍是另外的工作；本版不宣稱已完成這些功能。
